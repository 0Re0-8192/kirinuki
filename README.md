# kirinuki

切り取り&スケッチ(Snipping Tool)の代わりに常駐する、画面キャプチャと録画のツール。録画中の停止バーが CRD(Chrome リモート デスクトップ)や Virtual Desktop から見えるようにするために作った。

- 切り取り&スケッチの停止バーは画面の取り込みから除外されているらしく、CRD や VD からは見えない(推測)。
- kirinuki の停止バーは除外していないので、CRD や VD からも見える。それでも録画には映らないように、バーは録画範囲の外に置く。
- 録画は Desktop Duplication(CRD や VD と同じ取り込み方)を使う。

## 使い方

`dist\kirinuki.exe` を起動すると、タスクトレイに常駐する。

| 操作 | 動き |
|---|---|
| Win+Shift+S | 選択画面を開く(前回のモードのまま) |
| Win+Shift+R | 選択画面を動画モードで開く。録画中なら停止 |
| Esc / 右クリック | 選択をやめる |
| トレイアイコンを左クリック | 選択画面を開く。録画中なら停止 |
| トレイアイコンを右クリック | 録画を停止 / 保存先を開く / サインイン時に起動 / 終了 |
| 通知をクリック | 保存したファイルをエクスプローラーで表示 |

選択画面のツールバー: 範囲 / ウィンドウ / 全画面 | 静止画 / 動画 | (動画のとき)音あり・なし | 閉じる

- 静止画: クリップボードにコピー(画像)し、PNG で保存する。
- 動画: MP4(H.264 30fps + AAC、システムの音)。停止すると、ファイルをクリップボードにコピーする(チャットなどに貼り付けられる)。
- 停止バー: ● 経過時間 / 一時停止 / 停止。ドラッグで動かせる。録画範囲の外側には赤い枠が出る(録画には映らない)。

kirinuki を終了すると、Win+Shift+S は切り取り&スケッチに戻る。

## 設定

exe と同じフォルダーの `kirinuki.ini`。

```
save_dir=C:\Users\<ユーザー>\Pictures\kirinuki
audio=1
video=0
shape=rect
```

`save_dir` の既定はピクチャの下の `kirinuki`。`shape` は `rect` / `window` / `screen` のどれか。`video` と `shape` と `audio` は、選択画面で最後に選んだものが自動で保存される。

## 制約

- 管理者として動いているウィンドウが前面にあるとき、Win+Shift+S は横取りできない(Windows の仕様で、キーボードフックに届かない)。その場合は切り取り&スケッチが開く。
- 録画できるのは1つのモニターの中だけ。複数のモニターにまたがる範囲は、重なりが一番大きいモニターに切り詰める。
- 範囲がモニターいっぱいで外側に空きがないときは、別のモニターがあればそちらにバーを出す。無ければバーは範囲の中に入るが、録画ではその部分を灰色で塗りつぶす(ドラッグで範囲に重ねたときも同じ)。
- 録画中に Win+Shift+S で静止画を撮ると、選択画面を開いているあいだは録画が一時停止する。
- 回転したモニター(縦置き)は録画できない。録画中に解像度や配置を変えると、そこで録画を終えて保存する。
- マイクの音は録らない。

## ビルド

```
.\build.ps1          # release → dist\kirinuki.exe
.\build.ps1 -Debug
```

Rust(stable、MSVC)が要る。その PC だけの設定(`CARGO_HOME`、`TEMP`、cargo の場所など)は `build.local.ps1` に書くと、`build.ps1` が最初に読み込む(git には入れない)。

## 試験(tools\)

- `test_record.ps1`: 自前の試験用ウィンドウを録画する。そのあいだに、停止バーを Desktop Duplication で取り込めるかも確かめる。
- `test_dda_bar.ps1`: 録画中のバーと範囲を Desktop Duplication で撮る(CRD/VD から見えるかの確認)。
- `test_app.ps1`: 常駐版の一連の動き(Win+Shift+S、Esc、静止画、Win+Shift+R で録画と停止)。クリップボードには触らない。
- `test_modes.ps1`: ウィンドウ単位と全画面のモード。
- `test_full.ps1`: モニター全体の録画。エンコーダーが追いつくかと、範囲内のバーが塗りつぶされるか。
- `test_soak.ps1`: 長時間の録画で、メモリとハンドルの数が増えないか。

試験の出力は `%TEMP%\kirinuki_test` に置く。

### 整合性レベル

一部のサンドボックスの中で作った exe には「低」の整合性ラベルが付き、起動しても「低」で動いて保存先に書けない。`build.ps1` は、そのラベルが付いていたら「高」(上限なし=起動した親と同じ権限)に付け替える。「中」にすると、シェルが「高」で動いている PC では、通知から開いたエクスプローラーが「中」になり、ほかのアプリへドラッグ&ドロップできなくなる。
